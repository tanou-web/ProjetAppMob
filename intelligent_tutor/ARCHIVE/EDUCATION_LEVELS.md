## 📖 EXEMPLES PAR NIVEAU

### EXEMPLE CP (Cours Préparatoire):
```
Exercice: "Combien fait 2+3?"
Options: A) 4  B) 5  C) 6

Le modèle:
✅ Corrige la réponse
✅ Dit "Bravo!" ou "Essaye encore"
✅ Explique: "2+3 = 5"
✅ Recommande: Cours "Les additions simples"
```

### EXEMPLE CM2 (Cours Moyen 2):
```
Exercice: "Combien font 2.5 × 4?"
Réponse: "8"

Le modèle:
✅ Détecte l'erreur (oubli de la partie décimale)
✅ Explique: "2.5 × 4 = 10, pas 8"
✅ Recommande: Cours "Multiplication avec décimales"
```

### EXEMPLE 3ème (Troisième):
```
Exercice: "Résolvez: 3x + 5 = 20"
Réponse: "x = 6"

Le modèle:
✅ Détecte l'erreur (calcul incorrect)
✅ Explique: "3x + 5 = 20 → 3x = 15 → x = 5"
✅ Recommande: Cours "Équations du 1er degré"
✅ Prédit: "Score BAC: 12/20 si vous ne renforcez pas"
```

### EXEMPLE Terminale:
```
Exercice: "Dérivez f(x) = x³ + 2x² - 5"
Réponse: "f'(x) = 3x² + 4x"

Le modèle:
✅ Vérifie (Correct!)
✅ Explique les étapes
✅ Recommande: Exercices plus difficiles
✅ Prédit: "Vous êtes prêt pour l'examen"
```
